# Mini-Shelter

Таблица бронирований: номера по строкам, 30 дней по столбцам, брони окрашены по статусу оплаты
(зелёный — оплачено, жёлтый — частично, красный — не оплачено).

Без внешних зависимостей: Node.js + встроенный SQLite (`node:sqlite`). Вся база — один файл `data/guests.db`.
Сервер занимает ~60 МБ памяти, страница весит ~30 КБ — подойдёт любой старый компьютер и самый дешёвый VPS.

## Пароль

Вход по одному общему паролю. Он задаётся в файле `.env`:

```
PASSWORD=ваш-пароль
```

Без пароля сервер не запустится. После смены пароля перезапустите сервер — все старые входы будут сброшены.
После 10 неверных попыток адрес блокируется на 15 минут. Вход действует 30 дней, кнопка «Выйти» — в правом верхнем углу.

## Запуск на своём компьютере

Нужен Node.js 22.13 или новее.

```bash
npm start
```

Откройте http://localhost:3000. Другие компьютеры в той же сети (Wi‑Fi отеля) могут открыть `http://IP-этого-компьютера:3000`.

## Размещение на AWS EC2

Vercel, Netlify и подобные **не подходят**: у них нет постоянного диска, база будет теряться.

### 1. Сервер

- EC2 → Launch instance: **Ubuntu 24.04**, тип **t3.micro** (или t4g.nano/t3.nano — хватит с запасом).
- Security group, входящие правила: **22** (SSH, лучше только со своего IP), **80** и **443** (HTTP/HTTPS, отовсюду).
- Elastic IP → привяжите к инстансу, чтобы адрес не менялся после перезагрузки.

### 2. Домен

A-запись домена (например, `booking.example.com`) → Elastic IP.
Нет домена — можно временно использовать `1-2-3-4.sslip.io`, где `1-2-3-4` — ваш Elastic IP через дефисы.

### 3. Установка

```bash
ssh -i ключ.pem ubuntu@ELASTIC_IP

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker ubuntu && exit     # перезайдите по ssh после этого
```

С компьютера скопируйте проект (без `data/` и `.env`):

```bash
rsync -av --exclude data --exclude .env --exclude node_modules -e "ssh -i ключ.pem" ./ ubuntu@ELASTIC_IP:~/mini-shelter/
```

На сервере:

```bash
cd ~/mini-shelter
echo "PASSWORD=ваш-пароль" > .env && chmod 600 .env
DOMAIN=booking.example.com docker compose up -d --build
```

Через минуту сайт откроется по `https://booking.example.com` — сертификат Caddy получит и будет продлевать сам.
Контейнеры перезапускаются сами после перезагрузки сервера.

### Обновление и смена пароля

После изменений в коде скопируйте файлы тем же `rsync` и выполните на сервере:

```bash
DOMAIN=booking.example.com docker compose up -d --build
```

Смена пароля: измените `PASSWORD` в `.env` на сервере и выполните ту же команду.

### Резервные копии

База — это `~/mini-shelter/data/guests.db`. Ежедневная копия (на сервере, `crontab -e`):

```
0 3 * * * sqlite3 /home/ubuntu/mini-shelter/data/guests.db ".backup /home/ubuntu/backup-$(date +\%F).db"
```

(`sudo apt install sqlite3`.) Надёжнее — дополнительно включить снапшоты диска в EC2 → Lifecycle Manager.

### Настройки (переменные окружения)

| Переменная | По умолчанию     | Назначение             |
|------------|------------------|------------------------|
| `PASSWORD` | — (обязательно)  | пароль для входа       |
| `PORT`     | `3000`           | порт                   |
| `DB_PATH`  | `data/guests.db` | путь к файлу базы      |

## Резервная копия

Скопируйте файл `data/guests.db` (лучше при остановленном сервере) или на работающем:

```bash
sqlite3 data/guests.db ".backup backup-$(date +%F).db"
```

## Как пользоваться

- При первом запуске номерной фонд заносится автоматически — список в `defaultRooms()` в `server.js`. Номера Люкс (фиолетовые) и Делюкс (синие) выделены цветом.
- **+ Номер** или «+ Номер» внизу таблицы — добавить номер. Клик по номеру слева — переименовать, сменить категорию или удалить.
- Каждый день разделён на утро и вечер: бронь начинается вечером дня заезда и заканчивается утром дня выезда.
  Поэтому в день выезда одного гостя в тот же номер можно заселить следующего.
- Клик по пустой ячейке — бронь на одну ночь с этого дня. Протяните мышью от дня заезда до дня выезда, чтобы выбрать несколько ночей.
- Клик по брони — изменить или удалить. Пересекающиеся брони в одном номере не допускаются.
- «« Месяц», «‹ 7 дн.», «Сегодня», «7 дн. ›», «Месяц »» и поле даты — переключение периода.
